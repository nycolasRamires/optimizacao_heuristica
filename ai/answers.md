## 1. Defining Reinforcement Learning in Heuristic Terms

In computer science and mathematical optimization, a **heuristic** is a practical method, rule of thumb, or trial-and-error discovery shortcut used to solve complex problems when an exact analytical solution or exhaustive search is computationally intractable.

### Reinforcement Learning as a Heuristic Optimization Framework:
1. **Intractability of Analytical Control:**
   In non-linear, dynamic environments with obstacles (such as our 3-pillar arena), solving the continuous Bellman Optimality Equation $\nabla V^*(s) = 0$ in closed form is impossible due to the continuous state-action spaces (Bellman's "curse of dimensionality").
2. **Trial-and-Error Heuristic Discovery:**
   RL replaces exhaustive global planning with **sample-based, experiential heuristic search**. The agent does not know the arena geometry or obstacle equations a priori; instead, it generates trial actions, observes scalar consequences (rewards and penalties), and incrementally refines its decision-making heuristics.
3. **The Value Function ($Q$ or $V$) as an Admissible Evaluation Heuristic:**
   In classic graph search algorithms (like $A^*$), a heuristic function $h(n)$ estimates the cost-to-go from node $n$ to the goal. In RL, the Critic network $Q_\phi(s, a)$ serves this exact role: it acts as a **learned evaluation heuristic** that estimates the cumulative discounted return $\mathbb{E}\left[\sum_{t=0}^\infty \gamma^t R_t \mid s, a\right]$ from any given state-action pair.
4. **The Policy ($\pi_\theta$) as a Decision Heuristic:**
   The Actor network $\pi_\theta(a|s)$ serves as a **fast action-selection heuristic**: it maps high-dimensional sensory inputs (15 LiDAR rays, relative goal coordinates, and local velocities) directly to 3D continuous motor commands ($a_x, a_y, \omega$), pruning away the infinite continuum of suboptimal actions.
5. **Bi-Level Heuristic Synergy in This Project:**
   - **Inner Level (RL - Gradient-Based Heuristic Search):** Soft Actor-Critic (SAC) uses policy gradients to heuristically climb the value landscape defined by a fixed reward function.
   - **Outer Level (GA - Evolutionary Metaheuristic):** The Genetic Algorithm optimizes the *shape* of the heuristic reward landscape itself (17 reward/penalty coefficients), steering RL away from deceptive local attractors (such as the "U-Trap Paradox" or timid wall-hugging).

## 2. Reinforcement Learning in Machine Learning: Paradigm, Supervised vs. Non-Supervised, and ML Taxonomy

### Is RL a Supervised Method?
**NO. Reinforcement Learning is strictly NOT Supervised Learning.** It constitutes a distinct, third primary pillar of Machine Learning.

| Dimension | Supervised Learning (SL) | Reinforcement Learning (RL) |
| :--- | :--- | :--- |
| **Feedback Type** | **Instructive:** Provides ground-truth target $y^*$. The environment says *"You should have output exactly this."* | **Evaluative:** Provides scalar reward $R_t$. The environment says *"Here is how good or bad your action turned out to be."* |
| **Data Nature** | Static, pre-collected, independent and identically distributed (i.i.d.) dataset $\mathcal{D} = \{(x_i, y_i)\}$. | Active, sequential, non-i.i.d. trajectory data generated by closed-loop interaction ($s_{t+1} \sim P(\cdot \mid s_t, a_t)$). |
| **Data Distribution** | Fixed external distribution $p(x, y)$. | Dynamically controlled by the agent's current policy $\pi_\theta$ (distribution shift / active exploration). |
| **Credit Assignment** | Instantaneous: error $\mathcal{L}(y, \hat{y})$ is computed immediately for each isolated sample. | **Delayed Reward Problem:** An action taken at $t=10$ may cause a fatal collision or reach a goal at $t=150$. |
| **Exploration** | Not applicable (dataset is fixed). | **Exploration vs. Exploitation Trade-off:** The agent must balance exploiting known high-reward paths with exploring untried trajectories. |

### Categorization of Soft Actor-Critic (SAC) within RL:
1. **Model-Free:** Does not build a kinematic simulation inside the policy; learns end-to-end directly from environment transitions $(s, a, r, s', d)$.
2. **Actor-Critic:** Jointly optimizes a policy $\pi_\theta(a|s)$ (Actor) and twin state-action value functions $Q_{\phi_1}(s, a), Q_{\phi_2}(s, a)$ (Critics).
3. **Off-Policy with Experience Replay:** Uses a Replay Buffer $\mathcal{D}$ storing past experiences, allowing sample reuse and stabilized mini-batch updates.
4. **Continuous Action Domain:** Uses squashed Gaussian distributions ($a = \tanh(\mu + \sigma \odot \epsilon)$) for smooth physical accelerations.
5. **Maximum Entropy Framework (Entropy-Regularized):**
   Instead of solely maximizing return, SAC maximizes return *plus policy entropy*:
   $$J(\pi) = \sum_{t=0}^T \mathbb{E}_{(s_t, a_t)} \left[ R(s_t, a_t) + \alpha \mathcal{H}(\pi(\cdot \mid s_t)) \right]$$
   where $\mathcal{H}(\pi) = -\mathbb{E}[\log \pi(a|s)]$ is the Shannon entropy. This prevents premature policy collapse into deterministic wall collisions and encourages broad exploration of navigation corridors.

## 3. Explanation of the Implemented 3-Way Tournament Selection

Tournament selection is a genetic algorithm selection operator implemented in [`evolution.py`](file:///home/nycolas/m/evolution.py#L335-L355) within the multi-group reproduction cycle.

### Context in the Reproduction Cycle
In each generational transition, the population of size $N$ is divided into 4 functional groups:
- **Group 2 ($n_{\text{best}} = 4$):** Top elite survivors pass directly as unmutated exact clones (skipping retraining).
- **Group 3 ($C(n_{\text{best}}, 2) = 6$):** Offspring produced by pairwise crossover of the top elites.
- **Group 1 ($n_{\text{dead}}$):** Replacement offspring produced by random recombination of viable survivors.
- **Group 4 ($n_{\text{left}}$):** Non-elite surviving individuals selected via **3-Way Tournament Selection**.

### How the 3-Way Tournament ($k=3$) Works:

```
Available Non-Elite Survivors Pool (e.g., Candidates 4 through 18)
           │
           ├────────────────────────────┐
           ▼                            ▼
  [Step 1: Random Draw]        [Step 2: Compare Fitness]
  Uniformly sample k=3         Evaluate Effective Steps:
  candidates at random:        • Candidate A: 215.4 steps
  ┌───────────────────┐        • Candidate B: 182.3 steps  ◄── WINNER! (Lowest steps)
  │ Candidate A       │        • Candidate C: 248.9 steps
  │ Candidate B       │                 │
  │ Candidate C       │                 ▼
  └───────────────────┘        [Step 3: Advance to Next Gen]
                               Candidate B cloned into Group 4
                               (Unmutated, passes directly)
                                        │
                                        ▼
                               [Step 4: Remove Without Replacement]
                               Candidate B removed from pool to
                               prevent over-representation
```

### Exact Algorithmic Steps:
1. **Candidate Pool Formation:**
   Let $\mathcal{S}_{\text{candidates}} = \text{survivors}[n_{\text{best}}:]$ be the pool of all viable survivors that did not already pass into Group 2 as top elites.
2. **Uniform Bracket Sampling:**
   From the remaining candidates, $k = 3$ distinct individuals are chosen uniformly at random without replacement:
   $$\mathcal{T} = \{I_1, I_2, I_3\} \subset \mathcal{S}_{\text{candidates}}$$
3. **Deterministic Fitness Tournament:**
   The individuals compete strictly on **Effective Steps to Goal** (where lower is better, penalizing crashes/timeouts as 500 steps):
   $$\text{Winner} = \arg\min_{I \in \mathcal{T}} \text{Fitness}(I)$$
4. **Advance Without Mutation:**
   The winner's genome is deep-copied into the new generation (`origin="tournament_selected"`, `parent_ids=[winner.id]`, `is_mutated=False`).
5. **Diversity Safeguard (Removal Without Replacement):**
   The winner is removed from $\mathcal{S}_{\text{candidates}}$ for subsequent tournament draws in the same generation, ensuring that no single non-elite dominates multiple Group 4 slots.

### Engineering Rationale for Tournament Size $k=3$:
- **Selection Pressure Balance:**
  - If $k=1$ (Random Selection): Selection pressure is zero; poor individuals advance at the same rate as strong ones.
  - If $k \ge 10$: Selection pressure is excessively high; only the top 1–2 non-elites ever win, causing genetic diversity to collapse within 3 generations.
  - At **$k=3$**, the best individual in the bracket wins 100% of the time, but a moderately good individual (e.g., rank 8) can advance if drawn against ranks 10 and 12. This creates an optimal balance between **exploitation** of proven navigators and **exploration** of diverse reward genomes.

### Detailed Mathematical Specification of Network Modules

#### 1. Input Dimension: $\mathbb{R}^{19}$
- **`obs[0:15]` (LiDAR Rays, 15 floats):**
  Spans a forward $100^\circ$ Field of View centered along the drone's heading ($[-50^\circ, +50^\circ]$). Distances are computed analytically against 16 line segments (4 perimeter walls + 3 square pillars) via Numba-accelerated raycasting and scaled as $d_i / \text{max\_range} \in [0.0, 1.0]$.
- **`obs[15]` (Goal Distance, 1 float):**
  Distance in 2D Euclidean space from drone centroid $(x, y)$ to target waypoint $(x_g, y_g)$, scaled by $1 / \sqrt{10^2 + 10^2} \approx 1 / 14.142 \in [0.0, 1.0]$.
- **`obs[16]` (Goal Relative Angle, 1 float):**
  Angle between drone heading $\theta$ and target vector, computed in body coordinates:
  $$\phi_{\text{rel}} = \text{atan2}(y_{\text{local}}, x_{\text{local}}) / \pi \in [-1.0, 1.0]$$
- **`obs[17:19]` (Local Body Velocities, 2 floats):**
  Linear velocities projected into the drone's forward/lateral body frame $(v_x^{\text{local}}, v_y^{\text{local}})$, scaled by $1 / v_{\text{max}} = 1 / 3.0 \in [-1.0, 1.0]$.

#### 2. Actor Network (Policy $\pi_\theta$):
- **Hidden Layer 1:** Fully Connected (`Linear(19, 256)`) + **ReLU** activation.
- **Hidden Layer 2:** Fully Connected (`Linear(256, 256)`) + **ReLU** activation.
- **Output Heads:**
  - $\mu(s) = \mathbf{W}_\mu h_2 + \mathbf{b}_\mu \in \mathbb{R}^3$
  - $\log \sigma(s) = \text{clamp}(\mathbf{W}_\sigma h_2 + \mathbf{b}_\sigma, -20, 2) \in \mathbb{R}^3$
  - Continuous action generated via squashed Gaussian reparameterization:
    $$a = \tanh\left(\mu(s) + \sigma(s) \odot \epsilon\right), \quad \epsilon \sim \mathcal{N}(0, \mathbf{I}_{3})$$
- **Parameter Count:** $5,120 + 65,792 + 771 + 771 = \mathbf{72,454\text{ parameters}}$.

#### 3. Critic Network (Twin Soft Q-Networks $Q_{\phi_1}, Q_{\phi_2}$):
SAC employs the **Clipped Double-Q trick** to eliminate overestimation bias in continuous action spaces. Two identical, independently initialized critic networks ($Q_1$ and $Q_2$) are trained concurrently.
- **Input Dimension:** Concatenation of Observation ($19$) + Action ($3$) = **$\mathbb{R}^{22}$**.
- **Architecture of each Q-Network:**
  - **Hidden Layer 1:** `Linear(22, 256)` + **ReLU** activation ($5,888$ params)
  - **Hidden Layer 2:** `Linear(256, 256)` + **ReLU** activation ($65,792$ params)
  - **Output Layer:** `Linear(256, 1)` ($257$ params) $\implies$ Scalar estimated soft Q-value $\hat{Q}(s, a)$.
- **Parameter Count per Critic:** $71,937$ parameters $\times 2 = \mathbf{143,874\text{ parameters}}$.

#### 4. Total Model Size:
- Combined trainable parameters (Actor + Critic): **$216,328\text{ parameters}$** ($\approx 865\text{ KB}$ in FP32), ensuring ultra-fast GPU cache residency, rapid batched inference ($\sim 3,800\text{ steps/s}$), and low VRAM footprint ($\approx 450\text{ MB}$ per training worker).
